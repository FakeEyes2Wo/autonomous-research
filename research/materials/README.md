# Research materials

These files are offline reference copies collected during research. They are not default experiment inputs, and their presence does not constitute new experimental evidence. Experiments must declare their inputs explicitly and retain generated evidence in their own run directories.

Each topic directory keeps the original filename and source bytes:

- `early-exit-llm-fairness/`
- `confident-adaptive-language-modeling/`
- `computational-fairness-adaptive-neural-networks/`
- `llm-efficiency-index/`
- `vision-transformer-early-exit-fairness/`

The relocation mapping and SHA-256 evidence are recorded in `.runs/directory-reorganization/materials-before.json` and the corresponding after-move manifest.
