## 实际宿主验收

新建专用 `DSH_HOME` 与 `web` profile，将两个包链接到发布工作区，执行 profile `pnpm install --offline`，通过完整绝对路径指定本机 DSH 进行安装预检，再启动独立本地端口。未复用用户账号、模型凭据或实际运行中的 profile。

宿主探针确认 `auto-research` 出现在预设列表中，并通过 `sessionController.create` 创建该预设的空白会话。浏览器验证侧栏独立「科研工作台」入口、主内容区完整替换、无旧聊天分屏拖拽条、重复点击不更换 iframe、返回聊天、切换插件页和导航不刷新宿主页面；1440px 桌面与 390px 手机视口均无横向溢出，收起侧栏保留入口图标。

最终版本元数据及构建在同一隔离宿主重启后复核。模型请求和真实科研任务未执行。宿主探针没有声称根级 `autoresearchSettings` 服务存在；Web 对真实核心设置模块的回退桥接另由 API / integration 测试验证。

## 边界

- 浏览器大部分用例使用临时项目和受控宿主接口；只有上节明确列出的导航和预设/会话检查运行在真实 DSH。
- 研究角色响应与检索网络在自动测试中使用 fixture/mock。本次未运行真实模型任务或公开检索服务的新联网基准；旧记录不能替代本次结果。
- 真实 Tectonic 编译使用现有缓存，未覆盖全新机器首次下载 TeX 资源或所有字体/宏包组合。
- 外部编辑器入口验证 API 参数和异常提示，没有启动用户编辑器。macOS/Linux、其他 DSH 版本、npm registry 安装和发布未在本次验证。
- CPA 未改动，维持 0.1.0；本次未执行 CPA 测试。

合并后设置页浏览器用例曾暴露旧入口断言与包含 `planner` 的模糊选择器；断言已按保留的设置入口更新，角色选择器改为精确角色 ID。最终相关用例已通过。发布前审查指出的旧目录预设覆盖及不准确兼容承诺已修正，并完成回归。
