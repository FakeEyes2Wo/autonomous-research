## 行为

- 文献有稳定身份、版本、原文 hash、页码或文本定位。题录、摘要、全文、未读和部分解析分别显示。打开原文不会自行下载或建索引。
- 研究需显式设置 `literature.mode: lexical`。首次绑定的索引版本在恢复时保留，显式知识更新另记事件。模型实际接收的原文、完整提示词和检索/曝光回执可追溯。
- 实验负结果、执行错误和外部反证进入后续决策上下文。开发观察可启发新假设；正式结论仍要求新数据与受支持的独立验证器。反思修改引用后重新核对已登记来源。
- 文献语义判断绑定具体 claim 的版本及内容 hash；旧记录缺少绑定或 claim 产生后继版本时，判断标为 unknown、需要复核，保留原始判断和反证。该严格规则也适用于只改变状态的版本，避免默认沿用旧判断。
- 同一 research tree 投影假设、候选、实验任务及作业关联；完整历史存于不可变研究记录，树和 `HANDOFF.md` 可重建。
- `project_paper_run` 先有界探索项目。历史 README 和结果文件保持未核实状态；补充验证沿用研究预算与证据门槛。`research_run` 只传保存的 `runDir` 可恢复该项目流程。
- 本地实验执行权限由宿主 `localExperiments` 配置授予，模型不能生成或扩大权限。缺少权限时任务图暂停。未知作业结果继续核对原作业，不自动重提。

## 使用与边界

配置和命令见[核心 README](../../packages/autoresearch/README.md)及[Web README](../../packages/autoresearch-web/README.md)。本地进程树控制目前仅支持 Windows；CPU/GPU/货币硬计量仍为 null，不能把墙钟预算当作这些资源的保证。授权的本地程序拥有宿主进程权限，此执行器不是恶意代码沙箱。

论文来源定位正确不等同于语义支持成立。未知领域验证器、未验证历史结果和无法取得的原文保持 unknown。自动 OCR、图检索、远程调度与任意依赖产物自动铺设不在本轮完成范围。

```sh
node scripts/runtime-soak.mjs --duration-hours 24 --config test/fixtures/jobs/soak-config.json --output <空证据目录>
```
