## 升级注意

新运行在 legacy/minimal 模式下默认启用围绕当前想法的相似论文检索，使用 arXiv、Crossref 和 Semantic Scholar。默认 3–5 轮、每轮 4 个查询，最多 80 次 HTTP、200 个保留候选、每轮最多审阅 20 个候选，最终提供最多 20 个最相近候选，时限 10 分钟。可在项目设置中设 `workflow.currentIdeaSearch: never` 关闭；旧运行缺少此冻结策略字段时不会被自动启用。

检索报告仅供规划和想法审阅参考，不自动入库、刷新固定索引或成为科学证据。初始创意生成早于新 planner 检索钩子。完整配置与使用边界见[根 README](../../README.md#当前想法的相似论文检索)。

使用 Web 时保持 core/Web 同版本。当前仍从本仓库源码构建并链接到既有 DSH profile；此元数据调整不更改用户已经安装的宿主或依赖链接。更换宿主依赖版本后需要重新验收。
