# AutoResearch v0.2.1

- 发布日期：2026-10-19
- 产品版本：core / Web 均为 **0.2.1**；独立 CPA 保持 **0.1.0**。
- 对齐的 DSH：**0.2.1-rc.2**，产品使用其三段版本主体 **0.2.1**。
- 功能基线：v0.3.0，提交 `7e376842ffb22b2b96cfb1a5b5fc7e4f39c39f7f`。
- 发布形式：GitHub 源码正式版，不包含 npm 发布或预编译安装包。

## 本次编号纠正

按用户要求，产品版本改为与 DSH 版本主体对齐。**v0.2.1 替代之前的 v0.3.0，保留其全部功能。** 此次修改包版本、锁文件中的本地包版本、Web 对核心的版本声明和发布文档；业务源码、测试、预设、构建脚本及第三方依赖解析均未改变。

v0.3.0 标签保留原始指向，Release 标记为已被替代；v0.2.1 显式设置为 GitHub **Latest**。版本数字较小属于编号规则纠正，不是代码回退。根目录 [RELEASING.md](https://github.com/FakeEyes2Wo/autonomous-research/blob/v0.2.1/RELEASING.md) 已同步更新为优先对齐目标 DSH 的版本主体。

## 包含的功能

- 侧栏独立「科研工作台」入口，完整替换右侧主内容页面，支持返回聊天和切换会话，保护未保存编辑。
- UI 对齐研究流程、调度预算和 34 个科研角色；研究快捷操作填写原生聊天草稿，由用户确认发送。
- 实验完整验证与覆盖缺口检查；有预算上限的当前想法多轮论文检索。
- 文献阅读、真实 LaTeX/PDF 工作台、最终论文自动打开及编辑器入口。
- DSH 声明式预设安装、自定义配置保留、`DSH_HOME` 路径修复及发布规范。

## 兼容性与升级

宿主约束保持不变：Node.js `>=22.19.0`；DSH 为 `0.2.0-rc.1 || 0.2.1-rc.2`；Cordis 为 `~4.0.4`。版本主体对齐不表示 DSH 正式版 `0.2.1` 或其他宿主版本已经验证，也不扩大现有兼容范围。

已使用 v0.3.0 的用户保留项目配置和研究产物，切换到 v0.2.1 源码后，重新构建并将 profile 中核心和 Web 的链接同时指向该版本，重新安装 profile 依赖并重启宿主。核心和 Web 必须成对使用 0.2.1。本次不需要数据迁移。

从 v0.2.0 升级仍需注意宿主要求提高，DSH 0.1.x 不受支持。具体预设迁移、`--print-preset` 比对和安装步骤沿用 [功能基线的升级说明](https://github.com/FakeEyes2Wo/autonomous-research/blob/v0.3.0/docs/releases/v0.3.0.md#兼容性与升级)，其中源码版本和两个产品包版本应改用 **0.2.1**。

## 验证结果

- 本次重新执行：两个包的离线依赖安装、核心 typecheck 与构建、Web 构建与 **91/91** 测试、包版本/锁文件/peer 一致性及打包清单检查。
- 本次核对：业务源码、测试、预设、构建脚本和第三方依赖解析与 v0.3.0 完全一致。

具体证据见 [v0.2.1 编号纠正验证记录](https://github.com/FakeEyes2Wo/autonomous-research/blob/v0.2.1/docs/verification/2026-10-19-version-alignment-v0.2.1.md) 与 [功能基线验证记录](https://github.com/FakeEyes2Wo/autonomous-research/blob/v0.3.0/docs/verification/2026-10-18-release-v0.3.0.md)。

## 已知限制

已知限制沿用功能基线：没有新增真实模型端到端科研验收或公开检索联网基准，也未重新验证 macOS/Linux；PDF 编译仍需要本机编译器及相关资源。本次变更只修正产品编号，不改变这些能力边界。
