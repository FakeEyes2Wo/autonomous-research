# AutoResearch v0.3.0

- 发布日期：2026-10-18
- 上一版本：v0.2.0
- 包版本：`@athena/autoresearch` 0.3.0、`@athena/autoresearch-web` 0.3.0；独立的 `dsh-cpa` 维持 0.1.0。
- 本次实际验收环境：Windows、Node.js 24.4.1、DSH 0.2.1-rc.2、Cordis 4.0.5、Chrome、Tectonic。
- 本次为 GitHub 源码发布，不包含 npm 发布或预编译安装包。

## 主要变化

- **独立科研工作台**：侧栏新增明确的「科研工作台」入口，直接替换右侧主内容页面。支持「返回聊天」、切换侧栏页面和会话；重复进入不重载。未保存的论文编辑有离开确认，保存期间阻止误切换。
- **UI 对齐研究流程**：显示工作流模式、调度预算、论文改进轮数，并覆盖 34 个科研与论文角色。开始研究、设计实验、审查证据、撰写和改进论文会填入聊天草稿，由用户确认发送。
- **完整验证要求**：实验设计增加覆盖矩阵，完整性审查要求明确缺口；试跑成功不能替代正式验证。低调用流程保留目标结论所需的科学验证要求。
- **当前想法检索**：规划前支持有预算上限的多轮相似论文检索、查询规划与候选审阅，保存可追溯报告并支持恢复。新运行默认启用；既有运行缺失策略字段时保持关闭。相似度报告属于规划参考，不自动升级为研究证据。
- **论文与文献体验**：保留文献检索与阅读能力；自动发现最终论文，保护未保存草稿，支持通过宿主在本机编辑器中打开项目。
- **安装与发布维护**：安装器保留已有自定义预设和两种历史声明 ID，提供 `--print-preset`，首次修改 patch 时保存备份；修复预设变量与工作流插件适配，统一 `DSH_HOME` 路径解析，并新增根目录发布规范。

## 兼容性与升级

**宿主要求有不兼容变化。** Node.js 需为 `>=22.19.0`。本版本的 DSH peer 和 engine 声明仅包含 `0.2.0-rc.1 || 0.2.1-rc.2`，Cordis 为 `~4.0.4`；不再声明支持 DSH 0.1.x。核心锁文件的运行依赖保持 0.2.0-rc.1；本次实际宿主验收使用 0.2.1-rc.2。其他宿主版本需要单独验收。

1. 备份目标 DSH profile、项目 `.autoresearch` 配置、研究运行目录和论文；取得 `v0.3.0` 源码。已有源码部署可在独立目录使用 `git worktree add --detach <新目录> v0.3.0`，避免覆盖正在编辑的工作区。
2. 分别执行核心与 Web 的 `npm ci` 和 `npm run build`。Web 需与核心同步升级至 0.3.0，不混用不同产品版本。
3. 在核心包目录运行 `npm run install:dsh -- web --dsh-package <宿主 dsh/package.json 的绝对路径>`，将 `web` 替换为实际 profile。确认 profile 中两个包的本地链接指向本次源码，在 profile 中执行 `pnpm install`，然后完整重启该 profile 并创建新会话。
4. 安装器保留已有的自定义预设声明，不会自动覆盖成新版。已有声明可用 `node scripts/install-dsh-plugin.mjs --print-preset` 输出新模板后比对更新：移除不受宿主支持的 `{{cwd}}` 引用，并将旧 `dsh-workflow-worker-thread` 配置迁移为 `dsh-workflow-ptc`（`provider: spawn`）。旧 `.agent-presets` 文件保持原样；新版宿主使用 profile 内的声明式预设。

无法定位宿主时，安装器仅完成离线核心配置并提示指定宿主；检测到仅支持旧目录预设的宿主时在写入前退出。升级完成后从侧栏「科研工作台」进入；工作台不再占用聊天分屏，也无需拖拽调整聊天与工作台比例。

新运行可以通过 `workflow.currentIdeaSearch: never` 关闭当前想法检索，通过 `budget.currentIdeaSearch` 调整检索预算。此版本不执行破坏性数据迁移。回退时使用 v0.2.0 的源码、匹配宿主和备份配置，不移动已发布标签，也不要假设旧版可以解释新版运行的所有字段。

## 验证结果

- 核心 typecheck、构建和全量测试：**781/781 通过**；预设变量检查通过。
- 最终安装器回归：**8/8 通过**，覆盖幂等、旧声明识别、自定义配置保留、失败前置与只读模板输出。
- Web 常规 `npm ci`、构建和测试：**91/91 通过**。
- 5 组浏览器验收通过：设置页、原生工作台、真实 LaTeX/PDF 编译、文献阅读、最终论文自动打开与编辑器入口。
- DSH 0.2.1-rc.2 隔离宿主：23 个预设插件导入检查、预设加载、空白会话创建、桌面与窄屏工作台导航通过。
- 两个包的 `npm pack --dry-run` 及版本、锁文件、核心 peer 一致性检查通过。

完整范围及复现命令见 [v0.3.0 发布验证记录](https://github.com/FakeEyes2Wo/autonomous-research/blob/v0.3.0/docs/verification/2026-10-18-release-v0.3.0.md)。

## 已知问题与验证边界

- 本次没有运行真实模型的端到端科研任务，也未重新执行公开检索服务的联网基准；离线测试、宿主启动和论文编译不证明科研结论成立。
- 实际宿主 UI 验收使用无账号、无模型凭据的隔离 profile。原生模型请求、真实账号配置及 macOS/Linux 宿主未在本次重测。
- PDF 编译需要本机编译器及相应 TeX 资源；本次使用已有 Tectonic 缓存。缺少编译器时仍可编辑、保存和查看已有 PDF。
- 外部编辑器启动的浏览器测试验证的是宿主接口请求及失败提示，没有启动用户的桌面编辑器。

发布规则见 [RELEASING.md](https://github.com/FakeEyes2Wo/autonomous-research/blob/v0.3.0/RELEASING.md)。
