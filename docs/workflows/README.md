# 论文交接工作流

本目录保存两套可独立替换的 handoff 执行手册：

- [candidate-to-paper-handoff](candidate-to-paper-handoff/00-RUNBOOK.md)：从候选想法到论文。
- [records-paper-handoff](records-paper-handoff/00-RUNBOOK.md)：从已有实验记录到论文。

两套手册之间的交叉引用使用本目录下的相对路径；图管线验证使用 `../../../experiments/figure-validation/`，示例文章使用 `../../../examples_articles/`。实验数据与证据 JSON 不属于本次文档迁移范围。
