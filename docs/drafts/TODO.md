## Web 文献/PDF 阅读与论文预览

- [ ] 在 Web 页面增加“已找到的文献”入口：只展示核心检索结果或已登记的文献产物，不让浏览器提交任意文件路径或任意 URL。
- [ ] 增加 PDF 阅读器：页码跳转、缩放、适合宽度/单页模式、文本搜索和当前命中页定位；大文件使用受限的 HTTP `Range` 请求，不把整份文件一次性塞入状态。
- [ ] 增加 LaTeX 编译产物入口：区分源文档、构建任务和 PDF 版本，显示版本号、提交时间、产物哈希和当前/历史版本。
- [ ] 增加 PDF 产物刷新：刷新只能读取已登记的产物或已完成的构建任务，读请求不得隐式触发 `latexmk`、`pdflatex` 或任何外部命令。
- [ ] 展示编译状态与错误：`queued / running / succeeded / failed`，错误只显示受控的诊断摘要与日志定位信息，不把任意命令输出直接作为 HTML 渲染。
- [ ] 文件安全：服务端维护项目根目录和文献产物目录 allowlist；使用 canonical path 解析并拒绝 `..`、符号链接逃逸和未登记路径。浏览器只发送 opaque `projectId`、`artifactId`、`versionId`。
- [ ] 响应安全：仅允许登记的 `application/pdf`，校验 PDF magic bytes 和文件大小上限；使用 `Content-Disposition: inline`、禁用目录枚举，并严格实现有界 `Range`/`206` 响应。
- [ ] 访问控制：保持 DSH loopback/同源边界，拒绝跨源写请求；不把本地 PDF 路径、密钥或任意 shell 参数放进前端、URL、日志或导出配置。
- [ ] 测试：覆盖路径穿越、符号链接、错误 MIME、超大文件、非法 Range、过期版本、并发刷新和编译失败；确认“查看”不会创建构建任务。

暂不承诺浏览器端 PDF.js、LaTeX 编译器或远程文献下载已经接通；实现前应先确认 DSH 的产物/任务服务契约，并把阅读器作为独立的只读模块接入。
