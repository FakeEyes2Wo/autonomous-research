# AutoResearch 对话式科研工作台

## 用户确认的交互

- DSH 左上区域提供「科研工作台」入口，不必进入设置寻找。
- 保留原生 DSH 左侧工作区与会话导航；在原生主栏内展示工作台，页面使用 DSH 的主题、字体和控件风格。
- 一个科研项目就是一个 DSH 工作区目录。项目列表、文件根目录和会话归属均来自原生工作区，不另建一套项目选择或重复登记。
- 工作台上方保留左侧 LaTeX、右侧 PDF。
- 底部为横跨工作区的对话面板；用户已确认左右和底部微留空，不贴满窗口边缘。
- 使用 AutoResearch 生成论文后，在同一会话反复提出修改意见，继续改进结果。
- 延续上一轮要求：路径、资源、依赖和编译器配置可移植。

## 页面设计

原生左栏继续管理工作区、会话及折叠状态。右侧顶部改为紧凑导航，保留当前项目、当前论文、返回原生工具区。论文编辑和 PDF 使用主要区域，对话面板默认占主栏约三分之一；外侧保留约 16 px 留白，圆角边框，支持拖动调整高度、键盘调整及收起。缩窄到手机宽度时沿用原生侧栏折叠，上方仍用源码/PDF 切换，下方保留对话入口。论文 iframe 接收父页面的 DSH 颜色和字体变量，匹配原生明暗主题。

底部显示当前会话和真实 DSH 对话内容、输入区及模型/工具交互。常用操作提供「生成论文」「修改当前论文」「根据反馈完善」提示入口，让用户在原生输入框补充研究主题和要求后发送。界面不把 `/auto_research` 帮助命令伪装成一次论文生成操作，不创建新的模型凭据或聊天计费通道。

## 会话与文档

复用 DSH 原生会话服务、权限审批、工具调用和消息流；工作台与原生工具区切换后保持会话身份。左侧选中的工作区目录是唯一项目来源；上方仅显示目录名称，不提供独立项目下拉框。切换工作区或其中的会话时切换论文目录与科研会话，尚未选择目录时显示空状态。切换前的未保存论文草稿按工作区留在页面内存，回来后恢复；若磁盘已变化，保留草稿并继续使用原有版本冲突检查。

生成的 `main.tex`（包括 AutoResearch run 产物）可在项目允许范围内被发现。DSH 修改文件后，工作台检测源版本和产物变化：没有本地编辑时更新内容；有未保存编辑时仅显示更新提示，保留草稿。显示 PDF 是否与当前源文件一致；查看/轮询不隐式编译，生成或修改后的编译使用既有显式操作。

## 模块边界与迁移

原生导航与对话接入放在 Web 插件的客户端适配模块，通过 DSH 公共服务/插槽接入，不修改全局安装包。论文编辑/预览继续使用已打包的本地资源。跨 frame 消息若用于组合页面，必须检查同源和发送窗口，且只接收既定消息形状；浏览器不能指定任意服务器路径或命令。

原生工作区注册表作为目录权威来源，文档访问、生成产物发现遵守 canonical root、opaque ID 和同源/CSRF 边界；浏览器仅提交 workspace/project ID，不能指定服务器任意目录。对话仍由 DSH 自己保存；项目只保存论文和论文相关产物。

## 验收

1. 真实 DSH 左上入口可进入工作台，原生左侧工作区导航保留；底部有可用的原生对话界面，并可返回同一会话。
2. 在可控测试宿主中验证多轮对话触发工具更新临时论文，源码/产物变化可被发现；不向用户真实模型发送验收请求。
3. 未保存源码不被后台同步覆盖，切换项目没有旧会话/文档串入。
4. 对话面板边距、拖动、收起、窄屏可用，原有编辑/编译/迁移回归保持通过。
5. 实机验收明确区分已验证的原生 UI/会话接入与未调用真实研究模型的范围。
