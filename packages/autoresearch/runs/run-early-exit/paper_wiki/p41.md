## Implications / Insights

The criterion by which weights are pruned is itself a fairness lever; blind magnitude pruning can select the weights that protect minority groups.

## Relevance to Us

Demonstrates that the pruning criterion — the analogue of an early-exit confidence rule — can be tuned to protect minority groups.

## Abstract

Proposes a gradient-based pruning criterion that is fairness-aware for face attribute classification, so pruning keeps accuracy balanced across demographic groups while reducing computation.
