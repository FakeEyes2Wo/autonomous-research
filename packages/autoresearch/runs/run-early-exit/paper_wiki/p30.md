## One-liner

Introduces the StereoSet Score to quantify a pretrained LM's preference for stereotypical associations while accounting for fluency.

## Key Finding

Pretrained models exhibit substantial stereotype preference, and in several cases it increases with model scale/capability.

## Implications / Insights

Bigger, more capable models are not automatically fairer; bias can scale with capability, so capability gains must be audited separately.

## Relevance to Us

The stereotype-preference metric is a direct handle for testing whether an early-exit LLM emits more stereotypical completions when computation is budgeted.

## Abstract

StereoSet measures stereotypical bias using intrasentence and intersentence contexts across gender, race, religion, and profession, defining a StereoSet Score combining stereotype preference with a language-modeling score.
