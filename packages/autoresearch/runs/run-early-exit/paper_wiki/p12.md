## One-liner

Use a small draft model to guess tokens, then verify them in parallel with the big model for exact-distribution speedups.

## Key Finding

Speculative decoding achieves 2-3x faster decoding while provably producing the identical output distribution as the target model.

## Abstract

Introduces speculative decoding: a small draft model proposes tokens that a larger target model verifies in parallel, giving 2-3x wall-clock speedups while provably preserving the exact output distribution.
