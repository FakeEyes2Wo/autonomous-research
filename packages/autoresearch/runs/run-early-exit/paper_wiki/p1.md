## One-liner

Patience-based early exit for encoder transformers that waits for k agreeing predictions before stopping.

## Key Finding

Patience-based exits remain robust to noisy intermediate predictions, saving significant FLOPs with minimal accuracy loss and beating confidence-only early exits.

## Implications / Insights

The exit decision is input-dependent, so per-input compute is unequal (a seed of the fairness concern).

## Relevance to Us

Establishes the foundational input-conditional-compute mechanism that can allocate fewer layers to 'easy' (possibly group-skewed) inputs.

## Abstract

Adds inexpensive classification exits to every layer of BERT and stops inference early via a patience rule (k consecutive agreeing predictions), so easy inputs exit early and hard ones run deeper, cutting compute with little accuracy loss.
