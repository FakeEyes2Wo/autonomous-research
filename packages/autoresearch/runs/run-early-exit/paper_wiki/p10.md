## One-liner

Per-example depth-adaptive inference: each input exits at its own best depth.

## Key Finding

Combining per-example halting/classifiers with layer-specific classifiers lets models stop early on easy inputs while preserving quality on hard ones.

## Abstract

Proposes depth-adaptive computation in Transformers, letting each input decide how many layers to use (early exit) to reduce computation while preserving quality.
