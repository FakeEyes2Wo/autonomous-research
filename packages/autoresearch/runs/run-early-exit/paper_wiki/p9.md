## Key Finding

A small learned router can predict which layers an input needs without retraining the backbone, yielding compute savings with limited quality loss.

## Abstract

Trains a routing mechanism that selects a variable subset of decoder-only transformer layers to run per input, so different inputs use different effective depths.
