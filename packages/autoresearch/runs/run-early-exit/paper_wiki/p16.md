## One-liner

Lossless self-speculative decoding where an early exit acts as the draft model and the full model verifies.

## Key Finding

An early-exit draft from the same model can be verified by the full model to give exact match with baseline output while speeding up decoding.

## Relevance to Us

## Abstract

Proposes self-speculative decoding: the same LLM drafts tokens by exiting early from an intermediate layer, then verifies them with its full forward pass, yielding lossless acceleration without a separate draft model.
