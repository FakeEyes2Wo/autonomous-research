Per-token recursion depth improves the efficiency/quality frontier: harder tokens recurse more, easy tokens less, matching or beating dense baselines with less compute.

## Abstract

Introduces gated recursion depth where each token can recurse within a transformer block a variable number of times, giving token-wise adaptive depth and computation at inference.
