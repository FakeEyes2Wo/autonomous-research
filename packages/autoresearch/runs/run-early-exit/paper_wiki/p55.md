## Implications / Insights

Confidence can be learned as a first-class output rather than derived from logits, offering a controllable uncertainty signal for exit decisions.

## Relevance to Us

Suggests an alternative to raw logit confidence for early-exit decisions — a trainable, potentially group-calibrated signal.

## Abstract

Trains a model (T5) to express uncertainty in words given a question and a set of sampled answers, so the model can verbalize calibrated-confidence answers.
