## Implications / Insights

The threshold that decides compute spend is tuned globally on aggregate accuracy, so any group with lower confidence is handled differently.

## Relevance to Us

Illustrates that the threshold deciding compute spend is global, so systematically lower-confidence inputs get more compute (or are cut off and misclassified).

## Abstract

Inserts lightweight classifiers into intermediate BERT layers and exits per sample when confidence exceeds a threshold, accelerating inference while largely preserving accuracy.
