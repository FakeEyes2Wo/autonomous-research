## One-liner

Compute exact attention in tiles, never writing the full attention matrix to HBM, so it is faster and far more memory-efficient.

## Key Finding

FlashAttention delivers 2-4x wall-clock speedup and large memory savings, enabling much longer sequence lengths (refined in FlashAttention-2).

## Abstract

FlashAttention is an IO-aware exact attention algorithm that computes attention in tiles without materializing the large intermediate attention matrix, using recomputation to cut memory and improve wall-clock speed.
