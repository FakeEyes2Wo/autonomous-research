Compress LLM weights to 3-4 bits with a Hessian-based method that keeps accuracy nearly intact.

## Key Finding

GPTQ compresses LLMs to 3-4 bits per weight with only a small perplexity increase, giving 2-3x faster inference.

## Abstract

GPTQ is a one-shot weight quantization method based on approximate second-order information that compresses LLM weights to 3-4 bits while preserving accuracy.
