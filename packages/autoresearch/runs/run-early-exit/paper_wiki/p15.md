## One-liner

Jointly optimizes LLMs to (1) exit early and (2) feed an early-exit draft to the full model for lossless self-speculative decoding.

## Key Finding

Combining layer dropout with early-exit self-distillation lets a single model both accelerate via early exit and accelerate losslessly via self-speculation.

## Abstract

Trains LLMs with layer dropout plus early-exit loss so they can exit at intermediate layers; at inference these exits either provide direct early-exit output or serve as a draft for self-speculative decoding verified by the full model.
