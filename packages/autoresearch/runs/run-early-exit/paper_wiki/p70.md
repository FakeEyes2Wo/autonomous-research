## One-liner

Some transformer layers are nearly redundant or even harmful, so layer removal is surprisingly cheap.

## Key Finding

Many layers (including middle and some early ones) can be removed with minimal accuracy loss, revealing differential per-layer contribution.

## Implications / Insights

Since layer importance varies, the depth at which inference stops does not preserve information equally across inputs.

## Relevance to Us

Establishes that information is distributed unevenly across layers, so the layer at which inference exits determines what (and whose) information is preserved.

## Abstract

Investigates how much performance degrades when dropping individual (or groups of) layers from pretrained transformers, showing that not all layers contribute equally.
