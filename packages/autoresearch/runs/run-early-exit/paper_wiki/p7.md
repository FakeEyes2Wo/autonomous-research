## One-liner

A routing-based scheme where each layer processes only a top-k subset of tokens, dynamically allocating compute per token.

## Key Finding

Models can learn which tokens deserve more compute; capacity-based MoD matches or beats dense quality while using much fewer FLOPs per token.

## Implications / Insights

Token-level routing is learned, so which tokens receive more compute is an emergent, trainable property, potentially correlated with token frequency/domain.

## Relevance to Us

Key alternative to confidence exits: a learned router allocates compute per token, raising the same fairness-of-allocation question.

## Abstract

Routes each token through a variable number of transformer blocks via a learned top-k selection of which tokens occupy a block at each layer, allocating compute dynamically during training and inference.
