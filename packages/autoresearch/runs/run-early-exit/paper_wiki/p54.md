## Implications / Insights

## Relevance to Us

Supports per-group calibrated confidence as a route to fair early-exit thresholds, and warns that calibration data must be representative.

## Abstract

Proposes a universal calibration method (Thermometer) that calibrates LLMs across tasks and input distributions using a small set of labeled data, addressing the task-specificity of temperature scaling.
