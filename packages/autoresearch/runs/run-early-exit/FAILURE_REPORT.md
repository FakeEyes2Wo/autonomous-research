# FAILURE_REPORT

The frozen RUBRIC defines a quantization study (claims C1–C4) on Qwen3-4B-Instruct (primary) and Llama-3.1-8B-Instruct (robustness), using AutoGPTQ/AutoAWQ quantization, the entropy-temperature gate (A2) and Fair-GPTQ flip-aware weighting (A3), the occupation-set pronoun probe (O/W/U), and WikiText-2 calibration. The current ResearchTree contains NO evidence bearing on any of these claims. It instead documents a different, unrelated study: an early-exit/adaptive-depth fairness experiment on WinoBias with Qwen2.5-0.5B/1.5B backbones. None of it tests C1–C4, so no conclusion about the frozen hypothesis is supported.

Critically, the de-risk evidence (evi_c9d802a0) establishes hard, unmovable infrastructure blockers for the frozen protocol: the required quantizer libraries (bitsandbytes, auto-gptq, gptqmodel, autoawq) are all MISSING; the required checkpoints (Qwen3-4B-Instruct, Llama-3.1-8B-Instruct) are NOT cached (only ≤1.7B models are present); and the GPU has only ~8.6GB VRAM (insufficient to load Llama-3.1-8B fp16, and borderline for Qwen3-4B fp16 GPTQ calibration). The RUBRIC explicitly forbids substituting a different model/corpus (§11, §4.1 R8, R7) and mandates BLOCKED reporting for missing library/format support and unavailable WikiText-2. Since the primary experiment cannot be executed as specified and no reduced model may be substituted without violating the frozen protocol, no credible result toward C1–C4 is achievable. A failure report is warranted rather than continuing an off-protocol direction (early-exit), revising toward an infeasible plan, or finishing with insufficient evidence.
