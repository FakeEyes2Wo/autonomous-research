# Candidate

> 本文件只包含人类在没有任何证据时的先验模糊 idea，用于模拟 idea generation 的输入。
> 不包含论文结论、数字或 ground-truth 信息。

## Direction

LLM 微调之后经常出现一些说不清的行为：幻觉变多、反复说同样的话、偏好优化跑到后面反而变差。也许这些现象都能用同一个视角解释：训练过程中，一个训练样本如何逐步影响模型对其他样本/其他输出的预测。

## A-priori ideas（先验、无证据）

1. 应该把"学习动力学"（learning dynamics）做成分步的、可分解的影响分析：每步训练里，每个例子的影响如何在不同候选输出之间累积和转移。
2. 直觉上，指令微调和偏好微调（DPO 等）会以不同方式重新分配概率质量；某些被加强的"坏行为"可能不是模型学会了错误知识，而是影响在输出之间串了。
3. 偏好优化跑太久会退化，可能背后有一个可以被清晰描述的"挤压效应"，而不是单纯过拟合。
4. 如果这个影响分解框架成立，它应该不仅能解释现象，还能反过来给一个更稳的微调方法。
